# Working rules

- Never act on a guess. Inspect the relevant code, files, or behavior first and base changes on what is verified.
- If something is unclear or I am not sure, ask the user before proceeding with the uncertain part.
- Clearly distinguish confirmed facts from assumptions or unknowns.
- Do not invent missing project behavior, assets, configuration, or requirements.
- Keep `PROJECT_CONTEXT.md` current when verified project structure or behavior changes.
